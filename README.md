# Exercícios de POO (Java)

> **P2 · 2026.1** · Programação Orientada a Objetos

Exercícios da disciplina de POO em Java: classes, objetos, herança, encapsulamento e tratamento de dados.

| Pasta | Conteúdo |
|---|---|
| `01-atividade-1` | Atividade 1: classes `Aluno` e `Boletim` |
| `02-lista-1` | Lista 1: alunos e boletim, produto, e funcionários (herança: gerente e vendedor) |
| `03-lista-2` | Lista 2: questões 8 a 11 (conversores, validação de nulos, datas) |

Cada pasta é um projeto do IntelliJ: abra a pasta e execute a classe `Main`.

Projeto avaliativo da disciplina: [poo-cadastro-alunos-javafx](https://github.com/cauajoo/poo-cadastro-alunos-javafx).
